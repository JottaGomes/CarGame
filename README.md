# Revolta na Sala

Corrida de carro telecomandado em 3D numa sala de estar, feita com [three.js](https://threejs.org).
Três voltas: a 1.ª e a 3.ª pelo chão, por baixo das cadeiras, do sofá e do móvel da TV; a 2.ª por cima
do aparador, da mesa de vidro e da prateleira da TV.

É um único `index.html` sem build: abre-se diretamente no browser ou publica-se no GitHub Pages.

## Controlos

| Tecla | Ação |
| --- | --- |
| Setas / WASD | Conduzir |
| Espaço | Derrapar (travão de mão) |
| R | Voltar ao último checkpoint |
| C | Mudar de câmara |
| M | Som |
| P / Esc | Pausa |

No telemóvel aparecem botões no ecrã; um comando de jogo também funciona.
